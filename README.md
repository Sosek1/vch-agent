# vch: Video Changelog Hub agent plugin

A Claude Code plugin that turns a feature into a narrated demo draft in Video Changelog Hub. Your agent writes and runs a narrated Playwright walkthrough on the bundled recording fixture, uploads it, and the hub renders a film that zooms in on every action with an English voiceover. It ships the `vch` command, the `/vch:draft-demo` skill, and a session-start check that tells the agent whether you are logged in.

## Prerequisites

- An account on Video Changelog Hub, created for you by the author
- Claude Code (2.1.275 or newer)
- Node 22 or newer on PATH (runs `vch`)
- `@playwright/test` 1.61 or newer in the repo you record (the agent offers to install it)

## Install

In a Claude Code session:

```
/plugin install vch --marketplace Sosek1/vch-agent
```

Then start a new session and ask for a demo ("record a demo of <feature>").

## Note

`plugins/vch/` is generated by `scripts/build-plugin.mjs` in the app repo. Do not edit it by hand.
