# vch-agent

Claude Code marketplace for **`vch`**, the agent plugin of Video Changelog Hub.

## What the plugin does

`vch` turns a feature into a narrated demo draft from one prompt. Ask your agent to "make a demo of
&lt;feature&gt;" (or run `/vch:draft-demo`): it writes and runs a narrated Playwright walkthrough on the
plugin's recording fixture, writes the title and description, picks a product area from your hub's list, and
uploads the recording. The hub renders a film that zooms in on every action, with an English voiceover, as a
draft only you can see until you publish it. The plugin carries the `draft-demo` skill, the `vch` command
(login, upload, areas, fixture install) and a session-start check that tells the agent whether a login token
is saved on this machine.

## Before you start

The install is one step once these are true:

- An account on Video Changelog Hub. The author creates accounts; ask them if you do not have one yet.
- Claude Code 2.1.275 or newer (`claude --version`).
- Node.js 22.12 or newer on your `PATH` (`node --version`).
- `@playwright/test` 1.61 or newer in the repository you want to demo. The agent offers to install or upgrade
  it if it is missing or older.
- `autoMode.classifyAllShell` not set in your Claude Code settings. It suspends every shell allow rule, and
  the plugin cannot work around it.
- Optional: the rule `Bash(vch *)` (`/permissions` → Allow). A demo request does not need it; it only covers
  running `vch` outside one. A repository's committed settings may already carry it.

## Install

Type this in Claude Code:

```
/plugin install vch --marketplace Sosek1/vch-agent
```

Answer the scope question with **user** (the default), then exit and start a new session: the demo skill
appears only after a restart. The first time you ask for a demo, the agent offers to log in and prints a link
and a code; open the link, check the code matches, and approve.

## Layout

`plugins/vch/` is generated by the hub's release script from its own sources. Do not edit it by hand here;
changes made in this repository are overwritten by the next release.

## Problems

Report problems at <https://github.com/Sosek1/vch-agent/issues>. Include your `claude --version`,
`node --version` and the output of `vch status` (it prints no secrets).
